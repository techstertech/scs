# SCS 0.2.4 release

## Outcome and approved scope

Publish the existing remote-reranking fix as SCS 0.2.4 and replace the local
source installation with the verified public release. The user approved publication.
The existing GitHub Releases distribution procedure remains authoritative.

The reranker must honor `openai_compatible_trusted_hosts`, matching the existing
embedding configuration contract. Loopback defaults and exact case-insensitive
host matching remain. Wildcards and untrusted remote hosts remain rejected.
No public MCP schema, production dependency, or persisted-data format changes.

## Acceptance criteria

1. Python, Rust, runtime, tag, wheel, and installer identities agree on 0.2.4.
2. Local required checks and macOS/Linux hosted CI pass before tagging.
3. The immutable release contains both wheels, source, constraints, installer,
   SBOM, and checksums. Checksums and GitHub provenance verify.
4. The public macOS wheel reaches daemon readiness with the copied tailnet
   settings, preserving configuration and the empty local index.

## Verification plan

Run the identity checker and `just verify`; require main CI and release jobs.
Download release assets, check SHA-256 values, and verify attestations against
this repository and release workflow. Run the public installer and `scs doctor`.
Retain and compare the configuration checksum before and after installation.
Existing live embedding, reranking, and decision smoke requests passed through
MES on the tailnet. Cortex must remain running.

## Recovery

Published assets are immutable; corrections require another version. This release
has no data migration. The previous source commit can restore the local fix;
public 0.2.3 retains the remote-reranking defect. Do not reset indexes or settings.
