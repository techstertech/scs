# SCS 0.4.1 release

## Outcome and scope

Exclude vendored dependencies regardless of tree size. Publish version 0.4.1,
upgrade the local installation, and reconcile the affected repository. Keep
embedding concurrency, public APIs, and persisted formats unchanged. The user
approved updating TSG and rusqlite to resolve the release-blocking advisory.

## Evidence and design

The affected repository contains 419,373 vendor nodes out of 442,617 nodes.
The generated-directory size threshold permits this dependency tree. Move
`vendor` into the existing always-skipped directory set. Preserve the explicit
library-discovery opt-out. Full, incremental, and alias inputs use this owner.

## Acceptance criteria

1. Small vendor trees and aliases are excluded by Git, filesystem, and
   incremental discovery. Application files and explicit library discovery work.
2. Full reconciliation removes legacy vendor nodes, edges, vectors, and hashes
   while preserving application source and other projects.
3. Version sources agree. Targeted regressions and `just verify` pass. Publish
   immutable assets through the maintained macOS/Linux release workflow.
4. The dependency audit passes with patched SQLite. The user explicitly waived
   backups after the transfer failed; do not retry or require a backup.
5. Install the verified public release using cooperative daemon shutdown.
   Confirm installed identity, readiness, and successful affected-project indexing.
   Resume the queued property-spine request cancelled by upgrade shutdown.

## Recovery and boundaries

Use ordinary full reconciliation (`scs index`), which sweeps excluded paths;
force-snapshot `scs reindex` does not sweep. Do not delete a repository index.
If activation fails, use the previous verified installer for rollback. Preserve Cortex, terminal
sessions, credentials, source files, and unrelated services. No model-service
deployment or configuration change is included.

## Planned verification

Run discovery and pipeline tests, the release version checker, and `just verify`.
Verify hosted CI and release assets, then run installed version/import/doctor
checks. Observe reconciliation completion and query stored vendor counts.
Record executed results before sign-off.
